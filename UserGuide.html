CryptoScanner — Nobitex / IRT

This release is dedicated to spot trading on Nobitex in the IRT market.

Risk notice: no trading system guarantees profit. Use paper mode first and keep live exposure small.

1. Install

2. Nobitex credentials

Create a Nobitex API key with READ and TRADE permissions. Do not enable withdrawals.

Set NOBITEX_API_KEY and NOBITEX_PRIVATE_KEY, or enter them through Settings.

3. How entries are detected

  • The application scans Nobitex IRT market statistics.
  • It records the local price path between scans.
  • It rejects excessive spread and chase.
  • It checks volume and, for shortlisted entries, executable ask depth.
  • It uses a short momentum confirmation rather than relying on a single green candle.
  • During a broad BTC decline, normal alt entries are blocked; only exceptional local movers can pass the Eagle exception.

4. Position sizing

The default mode is risk_percent. The system calculates a position from account equity and stop distance, then applies single-position and total-exposure caps.

API order values remain in the Nobitex Rial-compatible unit. Toman conversion is for display only.

5. Live trading checklist

  1. Confirm Nobitex balance.
  2. Confirm IRT market.
  3. Confirm risk-per-trade and exposure caps.
  4. Confirm the key has no withdrawal permission.
  5. Run paper mode first.
  6. When going live, verify the first fill and protective stop manually.

6. Troubleshooting

Authentication error: verify the public key, private key, API permissions and PC clock.

Rate limit: reduce scan frequency and let the built-in retry/backoff complete.

No entries: this can be normal. The strategy deliberately rejects weak movement, wide spreads, insufficient volume, excessive chase and risk-limit violations.
